Two ways to get a page

Pick the one that fits you. You can switch later.

Instant

No website? We've got you.

Fill in your name, a tagline and your links. We render a fast, beautiful page - light and dark mode, six themes, nothing to host, nothing to pay.

{
  "mode": "instant",
  "owner": { "github": "you" },
  "page": {
    "type": "person",
    "title": "Your Name",
    "tagline": "What you're about",
    "theme": "sunrise"
  }
}
Point

Already hosting somewhere?

Point your name at GitHub Pages, Vercel, Netlify, Cloudflare Pages - anywhere. You keep your site; you get a friendlier address for it.

{
  "mode": "point",
  "owner": { "github": "you" },
  "records": {
    "CNAME": "you.github.io"
  }
}

See the page before you claim

An Instant page turns your title, links and About text into a small home on the web. This is an illustrative example, not a claimed address or a real person's profile.

The file behind it

Save as pages/your-page-name.json in your claim PR. Replace the GitHub username, title, text and example URL with your own. showcase: false keeps this example out of the gallery.

{
  "mode": "instant",
  "owner": {
    "github": "your-github-username"
  },
  "showcase": false,
  "page": {
    "type": "person",
    "title": "Your Name",
    "tagline": "Small projects, useful notes.",
    "theme": "sunrise",
    "links": [
      {
        "label": "Project notes",
        "url": "https://example.com"
      }
    ],
    "sections": [
      {
        "heading": "About",
        "text": "I build small tools and share what I learn along the way."
      }
    ]
  }
}
Title and tagline
page.title and page.tagline introduce you at the top.
Links and About
page.links makes the buttons; page.sections adds headings and text below them.
Your address
The filename sets the address, not the title. Check availability first; this sample does not reserve a name.

Which mode should I choose?

Choose Instant for a small profile

You want a title, a few links and some text, without managing a host or a build. Edit the JSON in a new PR whenever your page changes. Instant pages have no got-a.page ads or analytics.

Choose Point for your existing site

You already have a portfolio, blog or app and want to keep its design and hosting. Add your chosen address to your host before merge, then use its recommended DNS target. Follow the steps for your host.

Both modes need a GitHub account and a reviewed pull request. Each GitHub account can claim up to two pages. Availability is not a reservation. Instant pages publish after merge and the index refresh; Point pages also wait for DNS and your host's HTTPS certificate. If a merged page does not load, start here.

How claiming works

About a minute to propose your claim. Point mode also needs host setup.

1. Write your page file

Our guided form writes the JSON for you - no hand-editing needed.

2. Open a pull request

The form drops you into GitHub with everything prefilled. A friendly checker reviews it in seconds.

3. Connect and go live

Instant mode goes live after merge. For point mode, add the domain on your host before merge, then wait for DNS sync and HTTPS.
