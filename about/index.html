About

Everyone's got a page. This is the story of ours.

What got-a.page is

got-a.page is a free, community-run subdomain service, launched in October 2026. Anyone can claim name.got-a.page for a profile, product, project or community. A claim is one small JSON file and one pull request - no accounts on our side, nothing to pay.

Two ways to use it: instant pages, which we host and render for you in one of six themes, and point mode, which points your name at a site you already host on GitHub Pages, Vercel, Netlify or Cloudflare Pages. The docs walk through both.

Who runs it

got-a.page was started by Dhanush Nehru and is maintained by volunteers, in the open, on GitHub. Every claim, every rule and every line of the service lives in the got-a-page organization - the claim repo, the page renderer, this website and the docs. If something looks wrong, you can read the code and see exactly how it works.

Why it is free

The domain is paid for years ahead and everything else runs on free tiers: GitHub Pages serves this site, a Cloudflare Worker renders instant pages, and pull requests do the paperwork. Today there are no accounts on got-a.page itself and nothing to pay. Claimed pages carry no got-a.page analytics and no got-a.page ads.

How it is governed

  • One claim per name, reviewed as a public pull request.
  • Only you (or a maintainer) can edit or remove your page.
  • No phishing, scams, malware, impersonation, illegal or adult content - see the Terms.
  • Clear abuse comes down first and gets discussed after - the full policy is in ABUSE.md.

Contact

  • Help with a claim or the service: open an issue on the claim repo - real humans read them.
  • Report abuse: abuse@got-a.page - include the subdomain and what is wrong.
